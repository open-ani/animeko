# TV 评论页设计提案

状态：已根据用户评审实现。入口在条目标题下的评分，页面接入真实评论分页。

## 页面布局

- 从条目详情标题下的 Bangumi 评分进入，使用现有全屏模糊背景覆盖层。
- 以 960 × 540dp 为参考画布，左右保留 58dp，上下保留 36dp，不显示底部遥控器提示。
- 顶部固定显示「Review」及作品名，不显示评论图标。主内容左侧最多 284dp、列间距 36dp，右侧占剩余空间；窄视口收缩左列和间距。
- 左侧固定排列评分总览、评分分布、我的评分入口。右侧独立纵向滚动，默认显示两张完整评论卡及下一张的部分内容。
- 背景沿用详情页的炭灰、紫褐与橄榄色模糊图；正文与背景保持足够对比。评分星星和柱状图使用参考图中的浅蓝色。

## 左侧评分

- 标题为「总览」，旁边不显示 Bangumi 标识。大号平均分在左，星星与下方排名、评分人数共用右侧同一列并左对齐；窄视口改为上下排列。设计图使用 7.9、#310、3,703 人评分作为示例。
- 分布不另设标题，按 1–10 分显示十根底部对齐、圆角的实心柱，不绘制全高轨道。真实柱高和分段人数使用 `RatingInfo.count`。
- 总览及图表是信息展示，不为每个数字和柱子设置独立焦点。
- 下方「我的评分」胶囊是左列的操作入口，打开已有评分编辑覆盖层。未评分显示「我要评分」；未收藏沿用灰色但可聚焦按钮及收藏提示 tooltip。
- 平均分、排名或人数缺失时显示对应空态或省略，评分人数不能充当评论总数。

## 右侧评论

- 右侧只显示评论数量，不设「用户评论」标题。现有混合评论接口在分页未结束时返回 `offset + 本页条数 + 1`，这不是精确总数，因此按已加载数量显示「90+ 条评论」；分页结束后显示确切数量。首次加载使用占位符，绝不以评分人数代替评论数。
- 卡片包含头像、昵称、时间、来源、作者评分与两行正文预览。作者评分只显示星星及分数，不显示 `/10`；无评分时省略。
- 首版沿用共享分页顺序；不预设尚未接入的排序、筛选或点赞统计。
- 卡片高度参考 128dp、圆角约 20dp、内边距 18dp、卡片间距 12dp。字体放大时允许卡片增高，减少可见条数，不压缩正文字体。
- 整张卡片是一个焦点。默认使用轻描边和深色半透明底；聚焦后使用 2dp 白色描边、略亮底色，右上角箭头同步变为白底深色图标。不增加焦点缩放。
- 正文预览保留共享富文本和遮罩语义；剧透只显示提示，进入全文后仍需主动揭示。
- 列表右侧显示细滚动条；底部渐隐与露出的下一张卡片提示仍有内容。

## 遥控器行为

| 位置 / 操作 | 行为 |
| --- | --- |
| 首次进入 | 评论可用时聚焦第一条；重新进入恢复仍存在的评论及滚动位置 |
| 评论列表上 / 下 | 立即移焦到相邻评论，列表平滑滚动以尽量居中显示当前卡片；新的方向输入中断旧动画并继续导航，首尾按实际滚动范围限制 |
| 评论列表左键 | 进入左侧「我的评分」按钮 |
| 我的评分右键 | 回到此前聚焦的评论；目标被删除时选择相邻可用评论 |
| 评论确认键 | 在当前 Review 页上打开播放页同款居中弹窗，默认聚焦正文阅读区域 |
| 全文阅读 | 保留后方 Review 页面，正文独立上下滚动；底部固定横向图标胶囊操作栏，提供遮罩切换、链接、图片、投票、举报及原文等可用操作。左右选择操作，上键回到正文，正文滚到底部后下键回到上次操作。返回恢复原评论和列表位置 |
| 我的评分确认键 | 复用现有锚定评分编辑器，关闭后恢复该按钮 |
| 评论页返回键 | 关闭评论页，回到条目详情标题下的评分入口 |
| 边界 | 首条的上键、左列的左键、右列的右键不绕回其他内容 |

评论页不显示底部操作提示。评分编辑器继续保留它原有的操作说明。

## 加载与异常

- 评分信息和评论分别加载，右侧加载状态不清空左侧已有信息。
- 首次加载使用与评论卡匹配的骨架；空列表显示「暂无评论」，左侧评分入口仍可操作。
- 列表加载期间若用户已转到评分按钮，数据返回后不抢焦点。
- 加载失败在右侧提供聚焦可达的重试入口；追加失败显示在列表末尾，保留已有评论、焦点与滚动位置。
- 全文复用 foundation 的 `TvOptionModal`（从播放页抽出），不再创建新的全屏模糊阅读层；按共享富文本模型呈现链接、图片、引用和遮罩，相关操作通过遥控器可达的行展开。
- 评论页在子层打开时保持布局并隔离焦点，保证评分按钮坐标和列表位置不丢失；视口变化后仍能更新评分锚点。
- 子层关闭时忽略 Compose 临时分配到首条评论的焦点；完成入口恢复或用户主动导航后才更新评论焦点记忆。

- [Android TV 焦点指南](https://developer.android.com/design/ui/tv/guides/styles/focus-system)：一个活动焦点，通过描边及颜色表达状态。
- 结合本仓库 [TV 开发规范](../../contributing/tv-development.md) 和 [条目详情设计](../../contributing/code/tv-subject-details.md)，继续采用页面内覆盖层与稳定业务 ID 焦点恢复。
- 设计图为预览，示例评论并非抓取的真实用户评论。应用实现以评审后的布局、状态与共享数据能力为准。
