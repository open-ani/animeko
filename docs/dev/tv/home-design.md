# TV 探索页：沉浸式 Hero 与连续浏览

日期：2026-09-12。恢复第一稿方向，并落实用户对探索页的修改要求。实现位于
`app/shared/ui-exploration/src/androidTv`；这份文档替代第二稿。

## 范围与首屏

探索页直接组合详情页的
`TvDetailsHero`，使用同一套标题、评分、标签、首播年月和放送信息。简介使用最多两行的纯文字，省略 description card。标题和简介都预留两行高度，避免单行与双行内容切换时整块信息上下跳动；超出两行省略。背景使用
`TvDetailsBackdrop` 的图片裁切与遮罩，操作使用
`TvDetailsAction` 的磨砂胶囊。顶部不增加 Animeko 标识、应用名称或“探索”标题。主壳现有侧栏继续承担跨页面导航。

Hero 只有“番剧详情”按钮。热门数据沿用共享数据流，展示前 10 项，不新增独立热门栏目。按钮保持焦点时，左右键循环切换热门条目；确认打开当前条目详情。标题、元信息与简介执行 400ms fade + slide：右键从右侧入场、向左退场，左键相反；自动翻页向右。backdrop 固定在视口内，只做淡入淡出，不参与左右位移。操作按钮保留同一个焦点节点。圆点表示当前位置，每 6 秒自动翻页，不显示自动翻页进度条。离开按钮或页面进入后台时停止自动翻页；返回后重新计时。

继续观看来自共享的在看收藏流，保持业务排序。没有数量提示和“全部追番”按钮；空集合不渲染栏目。

## 两段转场

所有栏目与 Hero 前景都属于同一个纵向滚动容器。backdrop 是滚动容器之外的固定背景层，不随内容上下移动；浏览推荐时仍保留背景图淡出到取色光晕的过渡。

| 焦点位置           | 页面行为                                     |
|----------------|------------------------------------------|
| Hero 详情按钮      | 展开 Hero；显示热门条目的信息、背景、详情按钮和轮播圆点           |
| 从 Hero 下移到继续观看 | 页面保持顶端；Hero 收起，按钮和指示器淡出；信息与背景过渡到当前继续观看条目 |
| 在继续观看中左右移动     | 保持当前纵向位置，横向滚动卡片；Hero 跟随当前条目              |
| 从继续观看继续向下      | 整页滚动，Hero 一起离开视口；作品背景淡出，露出当前卡片图片取色的光晕    |
| 在推荐网格中上下移动     | 按正常页面滚动，将当前行放到稳定的阅读位置                    |
| 从推荐向上返回继续观看    | 恢复原继续观看卡片、横向位置和收起的 Hero                  |
| 从继续观看向上返回 Hero | 恢复热门条目与展开布局，焦点回到详情按钮                     |
| 继续观看为空         | Hero 下移直接进入推荐网格并滚走 Hero，跳过首栏收起状态         |
| 浏览时按返回         | 回到展开 Hero；Hero 层的返回继续交由主壳处理              |

焦点使用稳定的栏目与 subjectId；分页、重排不重置卡片身份。目标被移除时回退到可用条目。懒加载内容完成布局后才发起初始焦点，恢复焦点不依赖固定延时；滚动准备通过 TvFocusScope 的可取消事务处理。离开页面再返回时，恢复卡片与滚动位置，即使 Hero 当时不在视口内。分页展示状态随 TV ViewModel 保留，避免返回时继续观看短暂消失导致行位置跳动；返回动画结束前，页面拒绝自动分配新焦点。

## 卡片

| 栏目   | 呈现                                                                                                            | 确认行为                              |
|------|---------------------------------------------------------------------------------------------------------------|-----------------------------------|
| 继续观看 | 复用 `TvLandscapeCard(showTitle = false)`，宽度直接引用详情页 `RelatedCardWidth`（198dp）；标题、简介、续播状态、已看 / 总集数和进度条全部显示在 Hero | 有共享解析出的下一集 ID 时直接续播；否则打开详情。长按打开详情 |
| 为你推荐 | 沿用 TvLandscapeCard 与自适应网格，只在图片内部显示标题                                                                          | 打开条目详情                            |

Hero 中的进度条使用 Material 的
`LinearProgressIndicator`，表示已完成正片集数 / 正片总集数。统计实际标记看完的集数，不把最后看过的集数当作已看数量，不计入特别篇，也不伪装成视频播放时间进度。未开播、未开始、追至最新、已看完等情况使用共享状态文案。图片卡片保留作品名的无障碍描述，不显示标题、字幕、遮罩或进度。

## 组件复用

| 能力                  | 公共实现                                                                            |
|---------------------|---------------------------------------------------------------------------------|
| Hero 结构、标题、元信息、加载骨架 | `ui-subject-tv` 的 `TvDetailsHero`，详情页与探索页都调用它                                   |
| 简介和操作区              | 共享 Hero 的可选 introduction 与 actions 插槽；探索页省略简介卡片，两行简介和继续观看信息放入 supportingContent |
| 胶囊按钮与模糊源            | `TvDetailsAction` 与 `LocalTvDetailsActionBackdrop`                              |
| 背景图片与遮罩             | `TvDetailsBackdrop`；探索页外层仅协调切换与取色光晕                                             |
| 继续观看、推荐卡片           | `TvLandscapeCard`；继续观看关闭可见文字并保留长按操作                                             |

移除探索页独立的元信息、详情按钮、继续观看卡片实现，以及不再使用的简介补充请求。公共组件的默认参数继续保持详情页原有呈现和操作。

## 视觉参数

以 960 × 540dp TV 视口为参考：

| 项目               | 实现                                                              |
|------------------|-----------------------------------------------------------------|
| 底色 / 主要文字 / 次要文字 | #282629 / #F1F1F1 / #BFBDBF                                     |
| 左侧对齐             | 主壳侧栏 48dp，加探索页内边距 24dp                                          |
| Hero 高度          | 展开至少为视口的 66%，收起至少为 52%；大字体下按内容自然增高                              |
| 标题               | 展开 40sp / 60sp 行高，收起 30sp / 45sp 行高；固定两行占位，保留完整行盒以适配中文字体，最多两行文字 |
| 简介               | 14sp / 21sp 行高；固定两行占位，最多两行文字                                    |
| Hero 转场          | 350ms；高度、标题与操作区域联动                                              |
| 背景               | 卡片选择防抖 180ms，图片交叉淡入 400ms，取色光晕过渡 450ms                          |
| 轮播               | 最多 10 项；6 秒；仅显示 6dp 圆点，无自动翻页进度条                                 |
| 详情按钮             | 40dp 胶囊；聚焦反色，失焦磨砂背景                                             |
| 继续观看卡片           | 复用详情页的 198dp 宽度，18dp 间距；纯图片、焦点圈不缩放                              |
| 推荐卡片             | 基于现有 192dp 卡片宽度计算列数，再均分可用宽度；16dp 间距                             |
| 滚动阅读位置           | 当前卡片行距离顶部约 76dp；顶部与底部渐隐                                         |

图片优先使用已有 TMDB 横图，其次使用原封面，最后使用中性底色。取色在图片解码后进行，迟到的旧图片不能覆盖当前条目的颜色。

## 加载与空态

- 初始 Hero 加载展示文本和卡片结构对应的骨架，焦点与向下导航保持可用。
- 热门加载失败时提供重试；已有内容刷新时保留内容。
- 推荐首次加载和分页展示原位反馈；失败时保留可聚焦的重试入口。
- 重试成功或正在聚焦的条目被移除时，回到真实可用的卡片。
- 继续观看为空直接隐藏；未登录不会新增占据此栏的登录卡。

## 与 Google TV 启动器录屏对比

参考是用户提供的 `Screen_recording_20260911_012045.mp4`，不是对所有 Google TV 版本的统一描述。

| 对照项   | 录屏中的 Google TV                   | 本次探索页                           |
|-------|----------------------------------|---------------------------------|
| 首屏焦点  | Hero 的 Watch Now                 | Hero 的“番剧详情”，按要求移除直接观看          |
| 第一栏下移 | 顶部操作收起，Hero 切换为 Top picks 当前卡片信息 | 同样两段逻辑；第一栏替换为继续观看               |
| 横向选择  | 首栏选择改变 Hero 图文                   | 当前继续观看条目改变 Hero 图文              |
| 再向下   | Hero 与前面栏目一起滚走                   | 同一个纵向容器整体滚动                     |
| 深层背景  | 当前条目对应的深色主题氛围                    | 当前卡片图片提取的径向光晕                   |
| 向上返回  | 先恢复首栏上下文，再恢复原 Hero               | 同样恢复顺序，并记忆卡片身份与横向位置             |
| 栏目内容  | Top picks、应用、电影等多个横向栏目           | 继续观看与较小的推荐网格，沿用 Animeko 数据      |
| 视觉密度  | 首栏纯图片，信息位于 Hero                  | 同样为纯图片首栏；Hero 额外显示续播状态、已看集数和进度条 |
| 背景强度  | 滚动后的底色更暗、光晕更克制                   | 取色光晕更明显；当前实现保留第一稿的色彩表现          |
| 全局导航  | 顶部导航                             | 本轮限定探索页，使用项目已有侧栏                |

这里复现的是录屏的焦点和滚动逻辑，Hero 的视觉统一复用 Animeko 详情页。推荐网格、继续观看进度和详情入口是本次需求明确要求的差异，不把它们描述为与 Google TV 像素一致。
