# TV 首页

实现位于 `app/shared/ui-exploration/src/androidTv`。主页以 Google TV
1.0.877433387 的横向栏目、沉浸预览和轮播为交互参考，定位依据见
[Google TV 首页交互参考](google-tv-home-reference.md)。

## 页面组成

主壳的 navigation rail 负责跨页面导航。首页不包含顶部 tab row 和应用栏。

页面使用共享的热门、在看收藏和推荐分页数据，依次呈现：

1. 热门轮播：全部热门条目、标题、详情页元信息、两行简介、详情按钮及可滚动位置圆点。
2. 继续观看：存在在看收藏时显示，按共享业务排序。
3. 为你推荐：自适应列数的纵向分页网格，960dp 屏幕下为四列。

继续观看提供沉浸预览及横向选择记忆。没有在看收藏时，热门轮播下方直接显示推荐网格。
推荐网格上下移动保留列位置，末行不足时选择同排最接近的卡片；左右键仅在当前行移动。
卡片身份由栏目和 subjectId 共同组成。

## 布局和状态

背景独立于纵向列表，始终固定在视口。前景、首排和普通栏目属于同一个纵向列表。首页内容按自身视口裁剪，缩放背景与横移前景的绘制范围不能越过 navigation rail 的边界。

| 状态 | 呈现 |
| --- | --- |
| 热门轮播聚焦 | 使用详情页标题和元信息样式，标题最多两行；简介两行；按钮及圆点显示；首排露出上缘 |
| 首排聚焦 | 热门前景上移淡出；独立预览自下向上展开，显示标题、详情页元信息、简介、续播状态与观看进度；首排上移；背景跟随选择 |
| 普通栏目聚焦 | 前景随列表移出视口；背景画面淡出到低亮度取色背景；首行栏目标题放大，网格卡片使用公共横版卡片焦点样式 |
| 返回上一级 | 从普通栏目恢复首排及其选择，再向上恢复热门轮播 |
| 返回键 | 内容浏览时返回热门轮播；轮播层由主壳继续处理 |

继续观看卡片确认时使用共享状态提供的下一集 ID 续播；不存在可续播的集数时打开详情。
长按打开详情。其余番剧卡片及热门按钮打开详情。

热门轮播左右循环。手动切换重新计时，操作按钮保持同一个焦点节点。
自动轮播仅在按钮聚焦、页面 RESUMED 时运行，默认阅读间隔 12 秒，并使用无障碍建议的阅读时长。
轮播选择访问共享分页展示器，触发后续热门数据加载。圆点视口最多容纳五项，边缘留白允许首尾选中项也保持居中。
背景独立淡入；标题、元信息、简介和按钮外观属于同一个全宽页面，使用 500ms 五次缓出横移，无前景淡入淡出。
按钮焦点节点保持稳定，复用详情页 `TvDetailsActionVisual` 的胶囊、背景模糊和柔和聚焦光晕，文案为“更多详情”；横滑不参与尺寸过渡。

热门与沉浸预览的标题复用详情页 `TvDetailsTitle`：40sp 字号、54sp 行高、常规字重，最多两行；沉浸预览标题宽 620dp。
标题与正文均使用系统字体缩放。热门标题上方没有栏目标签，空的预览字段和对应间距隐藏。
继续观看区域获得焦点时，完整预览以底边为锚点纵向展开，离开时收起；从热门或推荐网格返回均触发显隐动画。
动画持续 250ms，沿用行变换的余弦曲线，文字保持原始比例与不透明度。
继续观看的标题下方显示评分、主标签和首映年月；简介下方将共享观看状态、放送/观看状态与总话数合并为一行，其下显示 20dp 高的圆角胶囊进度条。
进度条使用当前主题的 `primary` 绘制 1dp 描边与光晕，已看渐变取自 `primaryContainer` 和 `primary`，已播未看与轨道分别使用 `outlineVariant` 和 `surfaceContainerHighest`。切换调色板时即时更新，几何粒子保持白色高光。
条目切换时，已看和已播两段长度从当前值以 400ms 缓动过渡到目标值；连续切换可以从中间值转向。
进度只统计正片中标记为看过的剧集，已播数量按最新放送序号定位正片列表后计数，跨季度连续编号不作为数量。
进度条的无障碍描述提供「已看 / 已播 / 总集数」，完结时提供「已看 / 总集数」；未知数量使用「–」。
已看区域内的圆形、菱形和方形粒子从左向右循环，每个粒子带四层逐渐缩小、淡出的几何拖影；粒子数量随已看区域宽度变化。
粒子与完整拖影在右侧退出后循环，整个效果裁剪在已看区域的圆角内。
帧更新只影响已看区域的绘制，首页继续观看区域可见、持有焦点且生命周期为 RESUMED 时运行动画。
窗口失焦、零观看进度或系统动画时长比例为零时暂停；非零系统比例控制粒子流速。

## 视觉值

以下坐标对应 960 × 540dp 模拟器，navigation rail 占据左侧 48dp。

| 项目 | 值 |
| --- | --- |
| 内容左侧 | 页面内 10dp，屏幕坐标 58dp |
| 底色 | #0E0E0F |
| 主要 / 次要文字 | #E8EAED / #BDC1C6 |
| 热门与首排预览占位差 | 147dp |
| 首排卡片上缘 | 热门状态 494dp；首排聚焦状态 358dp |
| 首排卡片 | 153 × 86dp，12dp 圆角；聚焦显示描边，尺寸保持固定 |
| 推荐卡片 | 共享 `TvLandscapeCard`，等分可用宽度、16:9，8dp 图片圆角 |
| 卡片间距 | 继续观看 20dp，推荐网格 16dp |
| 栏目间额外间距 | 12dp（横向列表自身底部另有 12dp） |
| 描边 | 共享 `tvCardFocusBorder`，2.5dp 主题色，图片与描边间距 2dp；常驻预留 4.5dp 外框，不缩放 |
| 普通栏目阅读位置 | 栏目顶部 64dp，卡片未缩放上缘 120dp |
| 栏目标题 | 普通 16sp；栏目聚焦 26sp，包含继续观看 |
| 操作按钮 | 与详情页播放按钮共用样式：最小 40dp 高、胶囊圆角、水平内边距 22dp；聚焦浅色反色与 180ms 光晕，无尺寸缩放 |
| 位置圆点 | 8dp，间距 8dp，五项视口 72dp，右边距 56dp，选中项居中 |
| 行变换 | 250ms，余弦缓入缓出 |
| 聚焦曲线 | cubic-bezier(0.2, 0.1, 0, 1) |
| 行透明度 | 上方 0.2，当前 1，下方 0.6 |
| 内容切换 | 横滑 500ms 五次缓出；背景入场 750ms，背景展开/收起缩放 400ms；轮播阅读间隔 12 秒 |

推荐网格使用公共卡片的图片内片名及焦点描边。继续观看使用纯图片卡片，信息集中在上方预览。
热门与沉浸预览的元信息直接调用详情页 `TvDetailsMetadata`：评分、主标签、放送月份；放送/观看状态及总话数由共享的 `TvDetailsAiringInfo` 显示，在继续观看预览中与续播状态同处进度条上方。
`AiringLabelState` 使用收藏仓库的 `airingInfo` 和 `progressInfo`，选中番剧持续订阅同一数据流。
标题字体与详情页共享；番剧名称、简介、图片、收藏和播放行为来自 Animeko。

## 焦点和数据更新

焦点请求使用 `TvFocusScope`、业务身份锚点和可取消的 `requestPrepared`。
首次焦点等待页面完成布局及 RESUMED。离开详情后恢复纵向栏目、横向位置及番剧身份。
准备尚未组合的目标时，纵向自动可见性调整暂停，避免原卡片将画面拉回。
卡片完成布局会报告锚点已准备好；恢复不依赖固定延时或轮询。

目标已经组合时先交付焦点，再跟随新的选择滚动。新的方向输入取消旧准备任务。
刷新移除聚焦条目时选择同栏可用条目；整栏变空时选择首个非空栏目。
加载和失败保留可聚焦的状态入口；重试成功后进入推荐内容。

## 组件边界

`TvExplorationRoute` 订阅保留的分页展示状态和媒体状态。
`TvExplorationScreen` 管理前景状态、栏目选择、滚动与焦点。
`TvExplorationHero`、`TvExplorationRowItem`、`TvExplorationBackdrop`
分别负责前景、继续观看/推荐网格及背景。元信息复用详情页组件，推荐网格复用公共横版卡片。

`TvExplorationViewModel` 使用共享探索页数据流与收藏仓库，背景由图片服务提供。
屏幕不直接访问仓库、网络或可变缓存。

## 验证

`TvExplorationUiTest` 使用 `runAniComposeUiTest` 合成遥控器输入。
覆盖几何位置、卡片聚焦尺寸与栏目标题放大、网格方向与列记忆、连续反向、完整热门轮播、圆点居中、按钮横滑轮廓、续播、详情页标题样式、长标题、
大字体、缺失元信息、分页重排、条目移除、失败重试及跨页面恢复；继续观看另覆盖简介、状态、进度及元信息的顺序、状态同行、浅色描边、
已看/已播的条长过渡与中途反向、完结/未开始/未知总集数，以及整体纵向展开、反向和从推荐网格返回。
粒子验证通过帧间像素差确认运动只发生在已看区域，并覆盖后台暂停、恢复、零进度、满进度和系统关闭动画。
测试显式保存 PNG，
并断言焦点、坐标和文字布局；Android 的 screenshot matcher 空实现不作为验收依据。
