# 功能开关

功能开关让服务端决定一个功能对某个用户是什么配置，客户端不用发版就能灰度、抽样、做 A/B 实验或紧急关闭。
服务端的取值列表与分发规则（各取值的比例、名单和属性表，按用户固定分桶 / 每次请求随机，平台与版本条件）在后台配置，见 `ani-api-server/docs/feature-flags.md`。
本文说明客户端怎样拉取和使用开关。

## 模型

- 一个开关对一次请求的结果是一个 JSON 对象：后台为本次请求命中的取值配置的属性表（`properties`），由客户端按自己认识的键解析。
  没有命中任何取值（总开关关闭、关闭名单、平台 / 版本不符、没分到）时服务端返回 `{}`；服务端没有这个开关（没创建或已删除，404）或还没拉取到时客户端也用 `{}`。
  所以读每个属性都要给默认值，默认值就是「关闭」时的行为：后台删除或停用一个开关等于让客户端回到默认行为。
- `FeatureFlag`（`app/shared/app-data/.../domain/featureflag/`）枚举了客户端认识的开关：开关名 `key` 与后台配置一致，KDoc 写清它读哪些属性和默认值。
- `FeatureFlagConfig` 包装属性表，`boolean` / `string` / `int` / `long` / `double` 都是宽容读取：键不存在或类型不对返回默认值，后台配错不会让客户端崩溃；嵌套的对象和数组用 `get` 自己解析。
- 读取封装在 `FeatureFlagManager` 里：`config(flag)` 同步给当前配置，`configFlow(flag)` 跟随拉取更新；`consume(flag)` 给当前配置并在后台再拉一次，供按业务单位抽样（见下）。

## 拉取

`FeatureFlagManager` 在应用启动时由 Koin 创建并 `start()`：

1. 先用上次拉取并保存的快照（`dataStores.featureFlagStore`），这样启动早期读取的配置与上次一致，而不是先按默认值跑一会儿。
2. 等登录状态确定（`SessionStateProvider.stateFlow` 发出第一个值，即 token 刷新完成）后，对 `FeatureFlag` 里的每个开关各请求一次 `GET /v2/feature-flags/{key}`（并发）。
   请求带 Ani token 与安装 ID：服务端对登录用户按用户 id 固定分桶并应用名单，对未登录的请求按安装 ID 分桶。
3. 之后每当身份变化（登录、退出、换用户）再拉取一次。固定分桶的开关在登录前后可能得到不同的配置，这是预期行为。
4. 失败按 5 秒、30 秒、2 分钟重试，用尽后沿用快照或 `{}`，直到下次身份变化。

一次启动内，配置只在拉取成功时变化。按用户灰度的开关在用到时调用 `config`，或用 `configFlow` 观察。
要按业务单位（例如每次播放）抽样的开关，在每个单位开始时调用一次 `consume`：它返回当前配置供这个单位使用（单位内行为一致），同时后台再请求一次供下一个单位用；
后台配成「每次请求随机」策略，每个单位得到的就是一次独立的抽签。要改成按用户或按启动抽样，后台改策略即可，客户端代码不变。

快照不放进设置备份：固定分桶的结果属于这台设备或这个用户。

## 新增一个开关

1. 在 `FeatureFlag` 加一项，KDoc 写清读哪些属性、各自的默认值（即关闭时的行为）。
2. 在用到的地方注入 `FeatureFlagManager`，按用户灰度的开关用 `config` / `configFlow`，按业务单位抽样的用 `consume`，读属性时传默认值。
3. 在后台「功能开关」页创建同名开关，为取值配置属性（例如 `{"enabled": true}`）与策略；创建前客户端按默认值行为。按用户灰度用「固定分桶」，按事件抽样用「每次请求随机」并让客户端按业务单位 `consume`，做 A/B 实验就配置多个取值、各自不同的属性。

## 现有开关

| 开关 | 读取的属性 | 作用 |
|---|---|---|
| `play_flow_report` | `threshold: Double`，默认 `0` | 播放加载流程埋点 `play_flow`（见 [播放加载流程埋点](analytics-play-flow.md)）的上报比例：进入播放页时抽一个 `[0, 1)` 的随机数，小于 `threshold` 的播放会话才向 Analytics 发送，整个播放会话内一致。每个播放会话 `consume` 一次；抽样在客户端完成，后台配一个取值 `{"threshold": 0.3}`、比例与灰度 100% 即可。不发送时调试悬浮窗照常显示。 |
