# TV 条目详情页

实现遵循 [TV 开发规范](../tv-development.md)。入口为 `TvAniAppContent` 中的详情导航条目，
依赖经 `TvAppDependencies` 传入，由 `tvViewModel` 管理 `TvSubjectDetailsViewModel` 的生命周期。

## 第一阶段布局

页面参照 Google TV 条目详情：全屏背景、左侧与底部线性遮罩、两行大标题、元信息、
半宽简介卡片和三个胶囊操作。960 × 540dp 下水平留白 58dp、标题 40sp、简介卡片约 412 × 116dp，
按钮高 40dp。首屏底部露出选集区；下滚依次为剧照选集、圆形角色、圆形制作人员、横版关联条目和作品信息。
播放、收藏和评分按钮的半透明背景使用 Haze 采样当前页面的海报与遮罩，应用 24dp 模糊并裁切到胶囊内部；
文字、图标和焦点内容保持清晰。背景源与按钮是兄弟节点，不重复加载图片，也不把按钮内容录入模糊源。
聚焦沿用浅色反色，播放按钮额外显示 180ms 淡入淡出的柔和白色光晕；按钮尺寸和焦点区域保持不变。
模糊源仅作用于主页面操作区，覆盖层中重绘的收藏/评分入口沿用已模糊的全屏背景。
元信息评分进入全屏双栏 Review 页：固定左列显示总览、平均分、排名、评分人数、分布图和个人评分入口，右列独立分页滚动评论。
顶部只显示 Review 和作品名，右列只显示评论数量，无底部遥控器提示。混合接口分页未结束时的 `total` 是下界，显示已加载数量加 `+`，结束后显示确数。布局与交互见 [评论页设计](../../dev/tv/reviews-design.md)。
简介卡片聚焦时加亮背景和描边，右上角圆形箭头同步切换为浅色底、深色图标；整张卡片共用一个焦点目标。
卡片实现位于 `components/TvDetailsDescriptionCard`，角色、声优与制作人员介绍入口直接复用它。

初次加载使用 `TvSubjectDetailsPlaceholder`，标题行、元信息、简介和操作区与真实内容共用
`TvDetailsHeroLayout` 的 slots、宽度断点和留白；下方露出 16:9 选集骨架。
介绍卡片加载时，标题、图标、右上箭头、正文与“显示更多”全部使用骨架，保留整卡的焦点边界和加载语义。
播放位置只有一个带加载语义的临时焦点，没有点击操作；成功后交接播放，失败后交接重试。
人物行使用圆头像和两行文案骨架，关联作品使用横版卡片骨架，均由调用方提供 placeholder slot。
正在聚焦的列表占位加载完成后进入该行首项，其他列表更新不抢焦点；有内容的刷新保留原内容。
评论首批和追加加载使用头像、元信息及正文行组成的 `TvReviewPlaceholder`。
首批骨架逐张作为独立 Lazy 项，只有第一张承接状态焦点，避免居中滚动按整列高度计算。
所有骨架复用 `ui-foundation-tv` 的 `TvPlaceholderBlock`，与播放页评论保持相同淡入淡出效果。

评论全文与人物讨论共用 `detailsRedactMasks` / `detailsRevealMasks`：隐藏时替换正文及链接，
避免无障碍语义泄露内容；展开和举报仍使用原始评论。`CommentOverlayCleanupEffect` 观察分页刷新，
通过 `CommentsRefreshed` Intent 交给 VM 清理共享评论状态的已结算覆盖，保留在途操作。

背景滚动时逐步压暗和模糊；内容顶部有滚动渐隐。使用共享 AsyncImage 加载背景，
自定义 BiasAlignment 的裁切由 Compose 完成，解码器保留原图比例以免提前丢弃所需区域。
人物卡沿用 TV 焦点描边且不缩放，人物图片优先顶部裁切，机构标识完整适配；缺图保留圆形占位。

| 功能 | 共享入口与 TV 行为 |
| --- | --- |
| 元信息 | BGM 星形评分仅聚焦时显示描边，确认进入模糊背景的评论页；主标签（通常为第二个标签）、yyyy-MM 放送时间、共享 `AiringLabelState` 文案及强调状态 |
| 播放 | `SubjectProgressState` 提供按钮文案；VM 使用共享续播目标，再回退未看/首集，导航到播放页 |
| 选集 | 16:9 剧照卡横排，确认播放、长按切换看过状态；标题右侧打开全部剧集面板，按正片/其他分组 |
| 收藏 | 全屏模糊覆盖层，在原按钮的窗口坐标重绘入口，并在其上方显示 248dp 公共选项面板；共享状态处理修改、删除确认及看过后的全部标记提示 |
| 个人评分 | 未收藏时按钮置灰但可聚焦，焦点触发上方轻量 tooltip，点击不打开收藏提示面板。已收藏时锚定原按钮显示五颗星；整组聚焦，左右调整 0–10，确认提交，返回取消；0 清除评分，保留已有短评和隐私状态 |
| 简介 | 全屏 Description（本地化），固定标题和纯文字标签 FlowRow；标签自动换行，位于正文滚动区域外。正文带右侧滚动条，末尾显示放送开始、正片话数和别名 |
| 角色与制作人员 | 共享全量分页列表；进入独立角色或制作人员导航条目，详见 [TV 人物详情](tv-people-details.md) |
| 标签 | `SubjectSearchRepository`；搜索遵循搜索设置的 NSFW 和看过/抛弃过滤规则 |
| 关联条目 | 16:9 横排卡片，保留作品名和关系，确认进入对应条目 |
| 作品信息 | 位于关联条目下方，复用简介阅读页的放送开始、正片话数和别名；整块信息为一个阅读焦点，标题随焦点放大，正文不增加聚焦描边、底色或缩放 |

选集、角色、制作人员、关联条目和作品信息标题统一随所在区块焦点在 16sp 与 26sp 间过渡。
作品信息聚焦时，其余前景内容在 180ms 内淡到 50% 不透明度，移开焦点后恢复；背景与作品信息正文保持原有显示。
透明度只影响绘制，原有导航与返回路径保持可用。
全量列表转换成 `PagingData` 时必须显式提供终止加载状态，避免加载骨架在数据返回后继续显示。
`details/TvSubjectInformation` 供简介阅读页和主页面底部共用，缺失的字段继续省略，话数在剧集加载完成后显示。

详情操作面板在当前 Compose 页面内实现，不创建 `Dialog` 或 `Popup` 窗口。
未收藏评分提示使用非模态、不可聚焦的 tooltip `Popup`，随按钮焦点显示/隐藏，不拦截返回或抢走遥控器输入。
提示沿用公共选项面板的深色与浅描边，使用小提示图标、紧凑留白，与按钮间隔 12dp；宽度最多 280dp，长文案自动换行。
提示以 180ms 淡入并从下方 10dp 滑入；失焦后以 140ms 淡出并向下滑回，退场完成才移除 Popup，全程不接收焦点。
收藏和评分使用 foundation 的 `TvOptionsRow`、`TvOptionAnchors`、`TvAnchoredOptionLayout`、
`TvOptionPanel`；窗口坐标转换到覆盖层局部坐标后定位，面板宽度和高度受视口及按钮上方空间限制。
公共 API 见 [TV options 与覆盖层](tv-options.md)。
收藏选项内容位于 `collection/TvCollectionOptions`，播放页与详情页共用状态列表、取消收藏确认和
Watched 后的「全部标记为看过 / 只修改收藏状态」选项。提交期间直接禁用 `TvOptionRow`，
沿用公共置灰样式，不插入加载圆圈，不改变文字位置；失败后重新启用，页面继续管理请求身份与返回路径。
评分按钮左侧按 `RatingPanelAnchorFraction` 对齐面板的对应比例处，靠近屏幕边缘时优先保证面板完整显示。
覆盖层背景图关闭独立 crossfade，由整个 overlay 统一执行 180ms 入场淡入。

评分调节复用播放页倍速提取的 `TvOptionStepper`，两侧箭头仅反馈按键、不单独聚焦。
已有个人评分作为初始草稿；未评分时使用平均分四舍五入的整数，平均分缺失或无效时为 0。
草稿仅确认时提交，取消或关闭后清除；下次打开重新读取当前个人评分/平均分。
面板移除确认/取消按钮，底部显示本地化遥控器操作提示。

## 状态与文件归属

- 根包 Route 收集生命周期状态、处理导航及外部链接，并为恢复的标签面板连接数据。人物页由独立导航条目管理。
- ViewModel 组合共享条目状态、人物和搜索数据，执行业务 Intent；结果携带发起界面的请求编号。
- `presentation/TvSubjectPresentationState` 保存面板栈、聚焦项、返回目标和请求编号。
  旧操作完成后不关闭用户后来打开的面板。
- `components` 提供带 slot 的页面、全屏覆盖层和选项列表骨架，统一处理布局及焦点准备。
- `details` 组合首屏、圆形人物卡、横版关联卡、简介阅读页、评分及其他资料面板。
- `details/TvSubjectReviews` 协调双栏评论分页和焦点；`reviews` 提供总览、评论卡、遮罩安全预览和滚动提示。
- `TvSubjectDetailsDefaults` 集中保存布局尺寸、圆角和中性色。

刷新保留已有详情及稳定的分页流；新 PagingData 沿原流提交。共享剧集状态尚未就绪时，
不用空列表替换正在浏览的内容。列表删除按原位置恢复邻项，重排保持业务 ID。

## 焦点契约

| 场景 | 目标 |
| --- | --- |
| 首次进入 | 布局完成、窗口获焦且生命周期 RESUMED 后聚焦播放；用户导航可取消等待 |
| 操作栏 | 播放 → 收藏 → 评分；任一操作向上进入简介，向下恢复上次选集，首次进入使用续播目标，再回退首集；Lazy 目标先滚动再送焦 |
| 选集 | 上键到全部剧集入口，再上键回播放；下键到角色，角色上键恢复原选集。加载中或无剧集时入口保持可聚焦，下键可继续到角色；加载完成不抢走当前焦点 |
| 简介卡片 | 上键到 BGM 评分，下键回播放，确认打开全屏阅读页 |
| BGM 评分 | 下键回简介，确认打开评论页；关闭评论页恢复评分焦点 |
| Review | 首次聚焦第一条评论；上下移动并尽量居中显示评论，首尾受滚动边界限制；左键进入个人评分，右键恢复原评论。全文使用播放页共用的 `TvOptionModal` 居中弹窗，关闭后恢复原焦点及列表位置。数据删除时回退相邻业务 ID，异步加载不抢走评分按钮焦点 |
| 下方区块 | 选集 → 角色 → 制作人员 → 关联条目 → 作品信息；声明上下出口，行内左右沿连续列表导航 |
| 作品信息 | 整块聚焦，上键按业务 ID 回到进入前的关联条目，返回键回播放；关联条目仍在加载且无可用入口时，从制作人员直接进入作品信息，上键回原制作人员；异步数据变化后选择仍可用的入口 |
| 评分 | 默认聚焦整组调节控件；左右调分、确认提交、返回取消；下键到重绘入口，上键返回控件。提交期间保留焦点并阻止重复调整/提交，失败保留草稿及焦点 |
| 操作覆盖层 | 面板下边缘可进入原位置重绘的按钮，上键回面板，确认关闭当前层；背景页面保持组合但不接收焦点、按键或触摸 |
| 简介阅读 | 进入时聚焦第一个标签，无标签时聚焦正文；上下滚动正文，滚回顶部后上键进入标签，标签上下键逐行导航，最后一行下键回正文 |
| 二级返回 | 先关闭图片、人物详情或确认层，再按稳定 ID 恢复父面板 |
| 页面返回 | 弹层回入口；下方区块/简介卡片/BGM 评分回播放，播放处返回交给页面导航 |

首屏通过 BringIntoView 顶边锚点回到页顶。公共 `TvSubjectDetailsPageLayout` 在全部区块之后
追加独立的 192dp 留白 Box，Information 本身不再包含末尾 padding。
最后一个区块聚焦时，以该 Box 的底边对齐视口底边，让末节内容留在视口中部；
同一行内换焦点保持这个纵向锚点，留白本身不接收焦点。
其余人物及关联条目使用平台默认纵向滚动，
内层横向列表独立使用行首 + 58dp 锚点。Lazy 恢复先按业务 ID 滚动，再经 `requestPrepared`
等待附着、窗口和生命周期事件送焦，不使用固定延时或逐帧重试。

## 回归验证

`TvSubjectDetailsUiTest` 使用合成遥控器输入验证首屏几何、简介固定标题与长文滚动、
标签返回、评分上下界/草稿/失败、收藏及全部标记确认、选集播放/长按/记忆恢复、人物与关联导航、
删除/重排、加载错误重试、过期完成、放大字体、长按返回、BGM 评分进入评论页、
各行标题焦点变化和关联条目加载结束（包含空列表）。
作品信息另验证聚合语义、标题放大、周围内容淡出及恢复、上下/返回路径，以及关联条目加载中、空列表和大字体布局。
末尾留白验证独立焦点边界及其底边与视口底边对齐，包含大字体布局。
加载测试核对首屏骨架到真实内容的简介/操作区位置、圆形与横版列表几何、焦点交接及评论加载截图。
评论测试验证全文遮罩的隐藏/展开/收起语义；两种详情页均通过真实 Paging 刷新验证已结算投票
恢复服务端计数、在途投票保留本地覆盖。人物讨论还验证跨评论的过期举报结果和逐层返回。
另验证无 Dialog 窗口、覆盖层按钮与原按钮坐标/尺寸相等、面板位于按钮上方，
以及带偏移的窄视口和大字体布局、背景焦点隔离。

Android 的 `assertScreenshot` 目前不比较图片，因此测试另行捕获 PNG 到测试包 external files 目录。
对照截图时以 960 × 540dp 归一化检查几何、字级、遮罩和滚动状态；按钮、元信息和下方行的内容
按 Animeko 需求替换，不对不同海报素材计算无意义的整屏像素一致率。
测试海报仅打入测试 APK，来源和用途记录于测试 assets/README.md。

需要保留图片时，可安装测试 APK 后手动运行 instrumentation，再通过 adb pull 导出；
Gradle connected 测试清理 APK 时会移除该目录。手动执行须带
`runnerBuilder=de.mannodermaus.junit5.AndroidJUnit5Builder`。
测试 APK 的 page-size compatibility 避免 Android 16 兼容提示抢走测试焦点；
该配置不作用于正式应用。合成测试不能代替真实网络提交或原生播放链路的验证。
