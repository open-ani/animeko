# 分部条目的真实站点回归数据

`SeasonPartSiteDatasetTest` 用这些数据回归分部条目 (Bangumi 把一季拆成「X」「X 第2部分」等多个条目) 的过滤:
对每个分部组的每个采样剧集, 过滤后保留的 (站点条目, 集号) 必须是标准答案的子集, 标准答案非空时不能一个都不留.
每个文件是一个站点, `source` 为站点代号: girigiri, 稀饭动漫 (xifan), 嘀嗒影视 (dida), 叽哔动漫 (jibi), 森之屋动漫 (senfun),
嘀哩嘀哩 (dilidili), 热播之家 (rebo), 樱花动漫 (yinghua), 番茄动漫 (fanqie), 海星动漫 (haixing), 都来自默认订阅.

## 来源

分部组来自 Bangumi: 用「第2部分」「Part.2」「后半」「第2クール」等关键词搜出候选条目, 取其系列主线,
按名字识别出连续的分部 (后一个名字是前一个加分部标记, 或两者带相同季度序号且序号前相同), 共 43 组 90 个部分.
`mainline` 是该系列主线上的全部条目, 分部组内的条目带 Bangumi 全部别名, 其余只有中文名与原名; `mainEpisodeCount` 是正片集数.

`entries` 是在站点上用系列名搜到的条目及其第一条线路的集号 (抓取于 2026-10, 用各站点订阅配置跑 Selector 引擎解析出的集号, 不能解析的已去掉).
girigiri 用站点的搜索接口与条目页直接抓取, 其余站点用 `tools/datasource-test-mcp` 跑真实引擎.

## 标准答案

`cases` 按每个部分的第 1、中间、最后一集采样. 标准答案由站点条目的命名与编号结构推出, 不是看过视频:

- 以本部分命名的条目 (Bangumi 名字或站点叫法「Part 2」「第二季」「后半」): 集数够得上整个分部组的是站点用本部分的名字装了全部部分, 取偏移后的集号;
  否则按集号集合覆盖的区间判断: 从 1 起编号取 `ep`, 接着上一部分编号取偏移后的集号, 按全系列编号取 `sort`;
- 以前面部分或基础名命名、且集数覆盖到本部分的合并条目: 取偏移后的集号;
- 其他条目不是答案.

Bangumi 有第 0 话、站点条目集数与 Bangumi 对不上、或编号方式认不出的采样标为 `verifiable: false`, 测试跳过, `flags` 说明原因.
