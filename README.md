# Asset branch

Orphan branch that only stores binary assets referenced from pull requests and issues
(screenshots, design exports, ...). It is not part of the application and is never merged.

Reference files by commit SHA so that links keep working after later commits:

    https://raw.githubusercontent.com/open-ani/animeko/<sha>/<path>
